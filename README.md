## 👨🏻‍💻 About Me

I'm a **.NET developer** with hands-on experience building production-style web applications and database-driven solutions. My core focus is backend and full-stack web development using **ASP.NET Core MVC**, **Entity Framework Core**, and **SQL Server**, with a strong foundation in software engineering principles and object-oriented programming.
